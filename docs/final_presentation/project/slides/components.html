~60 seconds. Left: retrieval, the stage that dominated failures at the midterm. BM25 found the governing section first only 6% of the time. Dense plus BM25 hybrid tripled that; adding a prior toward the regulation the classifier predicts, then an LLM reranker that reads the complaint, took top-1 to 54%, and GPT with our labelling rubric to 77%. All settings were chosen on dev, held-out run once. Right: the checker. The SummaC-style NLI checker was only 70% balanced accuracy on regulation text; it misses dropped legal qualifiers. Averaging it with an LLM judge reached 83%, a significant +15 points. We also tried HHEM, AlignScore and Bespoke-MiniCheck; none beat the pair.
