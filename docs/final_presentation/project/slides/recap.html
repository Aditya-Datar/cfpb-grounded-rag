Prior work

Magesh et al. 2024: commercial legal RAG tools hallucinate 17–33%, but are scored end to end, so nobody can say which stage failed.

RAGAS (Es et al. 2024): "faithful" = matches whatever was retrieved, which is not legal correctness. SummaC: our sentence-level checker method.

What we add

Attribution: run every complaint with the retrieved passage and with the correct (oracle) passage; the gap is retrieval's fault, what remains is generation's.

We found no published work linking complaints to specific regulation sections.

Since the midterm

Midterm: BM25 only, 1 pilot, unvalidated checker.

Now: 5 retrievers + LLM reranker, checker validated on 150 labelled pairs, rewrite-on-flag, held-out evaluation, officer web app.

~60 seconds. Input: a consumer complaint filed with the CFPB. Output: product/issue, the federal regulation section that governs it, a draft reply citing that section, and a per-sentence report that flags unsupported sentences for a compliance officer. The tool assists an officer; it never replaces one. Prior work: Magesh et al. show commercial legal tools (Lexis+ AI, Westlaw) still hallucinate, but they score the whole system, so they cannot say whether retrieval or generation failed. RAGAS defines faithfulness relative to the retrieved text, which Magesh et al. reject for law. Our contribution is the attribution experiment: same complaint, retrieved vs correct passage. Since the midterm: the midterm had only BM25 and a pilot with an unvalidated checker at a lenient 0.5 cutoff. We added dense, hybrid, regulation-prior and LLM-reranked retrieval, validated and replaced the checker, added rewrite-on-flag, and evaluated once on a held-out half.
