Prior work

Magesh et al. 2024: commercial legal RAG tools hallucinate 17–33%, but are scored end to end, so nobody can say which stage failed.

RAGAS (Es et al. 2024): "faithful" = matches whatever was retrieved, which is not legal correctness. SummaC: our sentence-level checker method.

What we add

Attribution: run every complaint with the retrieved passage and with the correct (oracle) passage; the gap is retrieval's fault, what remains is generation's.

We found no published work linking complaints to specific regulation sections.

~60 seconds. Input: a consumer complaint filed with the CFPB. Output: product/issue, the federal regulation section that governs it, a draft reply citing that section, and a per-sentence report that flags unsupported sentences for a compliance officer. The tool assists an officer; it never replaces one. Prior work: Magesh et al. show commercial legal tools (Lexis+ AI, Westlaw) still hallucinate, but they score the whole system, so they cannot say whether retrieval or generation failed. RAGAS defines faithfulness relative to the retrieved text, which Magesh et al. reject for law. Our contribution is the attribution experiment: same complaint, retrieved vs correct passage. Since the midterm, against the plan we showed then: the midterm had only BM25 and a pilot with an unvalidated checker. We did each planned item: dense and hybrid retrieval plus an LLM reranker; the full attribution experiment on 127 complaints with a held-out half; the chunking ablation (structure-aware section chunks beat fixed 200-token windows by about 15 points hit@5); and a detector for complaints no corpus regulation governs (AUROC 0.74). The Streamlit demo became an officer web app. Three changes, each for a reason: the NLI checker scored only 0.70 against our labels, so we paired it with an LLM judge; once retrieval improved, generation became the bottleneck, so we added rewriting of flagged sentences; and credit-bureau dispute duties are in the FCRA statute rather than Reg V, so we added it to the corpus.
